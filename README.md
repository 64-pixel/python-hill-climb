# python-hill-climb
Hill climb game in python
This is an inspiration of the classic hill climb game, that you all played on you mobile phones. It is not a recreation 1 to 1, but i tried. It has 5 levels, which differ by the length of the track. There is a fuel system just like in the original, also there is music in main menu and in the game. 
How to play it:
Download my exe file and run it. 
The main controls are AD for forwards and backwards. The same goes for the right and left arrow. During climbing you can press escape button for pause menu, where you can restart continue or go to the main menu.
